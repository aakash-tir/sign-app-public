Sign App Architecture

ASL-teaching PWA (React + TS + Vite) · runs in the browser or a Capacitor WebView · no video leaves the device · on-device MediaPipe + classifiers · Python training pipeline · Cloudflare + Capacitor delivery

On-device recognition

  • • One shared camera stream (CameraProvider, ADR-018); MediaPipe Hand + Holistic landmarkers
  • • Static: JSON-weights MLP, 24 letters · Dynamic: TCN + attention ONNX (int8 weights), 103 of 114 classes published
  • • Temperature 0.8, per-sign accept bars, 3-window vote, 3-frame label stabilizer
  • • No TF.js; no video or landmarks leave the device

Build-time ML (Python, uv)

  • • WLASL + MS-ASL video and Kaggle ASL Alphabet images, local under ml/data/ (gitignored)
  • • dynamic_pipeline stages: extract · extract-combined · assemble-combined · pretrain · train · crossval · calibrate · diagnose
  • • Signer-disjoint honest gate (≥ 0.50 per sign) decides what ships
  • • Golden-vector fixtures keep TS and Python normalization identical

Delivery & storage

  • • Push to main → Cloudflare Workers Static Assets builds frontend/ and serves dist/
  • • CI: frontend.yml + ml.yml, pull_request only, with path filters
  • • Capacitor Android wrap proven (P6M2); store release is P6M9, owner-gated
  • • Progress is local-first in Dexie (v4), accessed only through repositories
