## Rewrite the README for public readers (#75)

**What we did**
Rewrote `README.md` for someone landing on the public repo: what the app is, the
live link, features, how recognition works, quick start for the app and the ML
pipeline (with its optional extras), repo layout, contributing and licence/data
terms. Also fixed `docs/README.md`, which still called the word model a GRU.

**The reason**
The repo went public on 2026-11-06 (sign-app-public). Its README still pointed
readers at `.claude/` (agent notes) instead of the `docs/` walkthrough, had no live
link or feature list, and didn't mention the ML extras. On a fresh public clone,
15 pytest tests skip silently without `--extra train`. #66 had swapped the GRU
for a TCN, but the docs index still said GRU.

**How it was solved**
- Before writing, ran every gate on a fresh clone of the public repo: Prettier,
  ESLint, tsc, 321 Vitest, 29 Playwright, build; ruff, mypy, 103 pytest passed +
  15 skipped (torch not installed). The public `frontend/`, `ml/` and `tools/`
  trees are byte-identical to private `main`; only `graphify-out/` differs
  (redacted home path).
- Checked the README's claims against the code: 107 `SHIPPED_GLOSSES`; no Vite
  port override (5173); no analytics code in `frontend/`; `dynamic_pipeline
  --help` runs. The tracking line says "no analytics code" rather than "no
  tracking", because hosting-side settings aren't visible from the repo.
- **Docs-only:** no architecture diagram update.
