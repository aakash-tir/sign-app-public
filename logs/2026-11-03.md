# 2026-11-03

## Brought the project rules, CI and GitHub setup in line with Nova and Skillbook (#59)

**What we did**
- Replaced the single `ci.yml` (push to `main` + every PR, no path filters, Node 20,
  `checkout@v4`) with one workflow per area, `frontend.yml` and `ml.yml`. They run on
  pull requests only, plus `workflow_dispatch`, with workflow-level `paths:` filters.
  Node goes to 24 and the actions to their current majors, `uv sync --locked`,
  `permissions: contents: read`, timeouts, and a Playwright results upload on failure.
- Added `.claude/hooks/protect-main.sh` and `graphify-guard.sh`, wired in
  `.claude/settings.json`, which was empty before. Added a PR template and bug/feature
  issue templates.
- Rewrote `.claude/rules/workflow.md` as the issue → PR → CI loop: one issue per PR,
  `<type>/<n>-<slug>` branches, merge only on all-green, out-of-scope finds become
  issues. Kept the stop-and-ask secrets policy and the gates.
- Added the shared required blocks to `.claude/CLAUDE.md`: git workflow, issues/CI,
  before-merge artifacts, backlog, where things belong, change log, secrets. Moved the
  ~120-line status narrative into `progress.md` and left a short summary.
- Created `docs/future.md` (backlog collected from CLAUDE.md, phase6.md and
  progress.md), this `logs/` folder, a code-only `graphify-out/` graph and
  `docs/architecture/architecture-diagram.html`. Moved `output.md` →
  `docs/history/phase2-analysis.md` to keep the root clean. Added
  `logs/*.md merge=union` and ignored graphify backups.
- On GitHub: labels (type, `area:*`, `blocked`, `needs-decision`), milestones
  `P6M8`/`P6M9`, issues #60–#62 for the remaining Phase-6 work, and squash-only merges
  with branch auto-delete.

**The reason**
The owner's newer projects settled on lean, PR-only, path-filtered CI (limited free
Actions minutes), issue-driven work, and a few always-current artifacts (log, backlog,
graph, diagram). sign-app predates them. Its CI re-ran both lanes on every merge to
`main`, even for docs-only changes. Nothing locally stopped a commit to `main`.
Status lived in a 178-line CLAUDE.md loaded every turn.

**How it was solved**
Ported the Skillbook/Nova files and adapted them to the two lanes here. The `ml` lane
also triggers on `frontend/src/recognition/fixtures/**`, because the Python parity
tests read those golden vectors. The graph is code-only (`graphify extract .
--code-only`) to avoid LLM cost. `.claude/docs/` stays where it is: it's the working
notebook Claude loads, and `docs/` is already the human walkthrough. The architecture
diagram is new (the first one), and this entry covers it.
